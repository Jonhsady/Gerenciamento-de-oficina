🚀 INSTALAÇÃO PASSO A PASSO:

1️⃣ EXTRAIR O ARQUIVO
   - Extraia o arquivo IDEIAS.zip
   - Você terá uma pasta chamada "IDEIAS"

2️⃣ ABRIR O TERMINAL
   - Abra o terminal/prompt de comando
   - Navegue até a pasta:
     
     cd caminho/para/IDEIAS

3️⃣ INSTALAR DEPENDÊNCIAS DO SERVIDOR
   
   npm install

   (Aguarde alguns minutos...)

4️⃣ INSTALAR DEPENDÊNCIAS DO CLIENTE
   
   cd client
   npm install
   cd ..

   (Aguarde alguns minutos...)

5️⃣ INICIAR O SISTEMA
   
   npm run dev

   ✅ Se tudo der certo, você verá:
   - Servidor rodando na porta 3000
   - Cliente rodando na porta 5173

6️⃣ ACESSAR NO NAVEGADOR
   
   Abra: http://localhost:5173

   🔑 Senha: admin123

❓ RESOLUÇÃO DE PROBLEMAS:

🔴 ERRO: "npm não é reconhecido"
   ➜ Instale o Node.js: https://nodejs.org/

🔴 ERRO: "Porta 3000 já está em uso"
   ➜ Feche outros programas usando a porta ou mude no .env

🔴 ERRO: "Cannot find module"
   ➜ Delete node_modules e reinstale:
     rm -rf node_modules
     npm install

🔴 Banco de dados corrompido
   ➜ Delete o arquivo database/oficina.db
   ➜ Reinicie o servidor (será recriado automaticamente)
