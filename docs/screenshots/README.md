# 📸 Screenshots

Esta pasta contém as screenshots do sistema para uso no README.

## Como adicionar screenshots:

1. Capture as telas principais do sistema
2. Salve as imagens nesta pasta com os seguintes nomes:
   - `dashboard.png` - Tela do dashboard
   - `clientes.png` - Tela de clientes
   - `servicos.png` - Tela de serviços
   - `pecas.png` - Tela de peças
   - `ferramentas.png` - Tela de ferramentas
   - `ordens-servico.png` - Tela de ordens de serviço
   - `usuarios.png` - Tela de gerenciamento de usuários
   - `login.png` - Tela de login

3. Recomendações:
   - Formato: PNG ou JPG
   - Tamanho recomendado: 1920x1080 ou similar
   - Qualidade: Alta resolução para melhor visualização
   - Nome dos arquivos: Use apenas letras minúsculas e hífens

## Exemplo de captura:

Use ferramentas como:
- **Linux**: `gnome-screenshot`, `flameshot`, ou `scrot`
- **Windows**: `Snipping Tool` ou `Win + Shift + S`
- **Mac**: `Cmd + Shift + 4`

Ou simplesmente use a extensão do navegador para capturar a tela completa.
